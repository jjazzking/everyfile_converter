# 브라우저 전환 사전 검증 결과

1단계(브라우저 전용 전환) 착수 전에 확인해야 했던 두 가지를 실측한 기록이다.
결론부터: **둘 다 통과**. 1단계를 브라우저 전용으로 진행해도 되고, 2단계 PDF 도 브라우저에 들어간다.

## 1. 엔진이 브라우저에서 그대로 도는가 — 통과

Pyodide 314.0.6 (Python 3.14.2) 에 `everyfile` 휠과 openpyxl 을 올려 실행했다.
**엔진 코드는 한 줄도 고치지 않았다.**

결과가 서버와 완전히 동일하다:

```
계정코드 '0110' · 날짜 2026-01-05 · 괄호음수 -240000 · 행수 11
```

선행 0 보존, 날짜 정규화, 괄호 음수, 소계 행 제외가 모두 서버와 같게 나왔다.
엔진이 순수 파이썬 + openpyxl 이라는 점이 그대로 값을 했다.

### 성능

| 행 수 | 파일 크기 | 최초 읽기 | 타입 변경 시 재계산 |
|---|---|---|---|
| 1,000 | 0.0MB | 0.13초 | 0.05초 |
| 5,000 | 0.2MB | 0.49초 | 0.22초 |
| 10,000 | 0.4MB | 1.11초 | 0.39초 |
| 30,000 | 1.0MB | 3.56초 | 1.25초 |

비교: 같은 작업을 서버(CPython)에서 돌렸을 때 8,412행 재계산이 0.53초였다.
**브라우저가 서버보다 느리지 않다.** 타입 배지 클릭의 체감은 1만 행에서 0.4초로 충분히 쓸만하다.

실무 상한은 3만 행 근처로 본다. 그 이상은 최초 읽기가 4초를 넘어가므로,
화면에서 CLI 또는 사내 서버로 안내하는 편이 낫다.

## 2. PDF 표 추출이 브라우저에서 되는가 — 통과 (단서 있음)

### 추출 동작 확인

pdfplumber 0.11.10 으로 격자 표가 있는 PDF 를 파싱했다.

```
표 1개 인식, 첫 표 4행 x 5열
    ['Counterparty', '30d', '60d', '90d', 'Total']
    ['Daehan Corp', '34,500', '0', '0', '34,500']
    ...
좌표: 'Accounts' → x0=60.0 top=61.3 x1=110.1 bottom=72.3
```

셀마다 bbox 가 나오므로 설계 때 그린 **원본 좌표 하이라이트 검수 화면**을 만들 수 있다.
`SourceRef.page` / `bbox` / `confidence` 자리를 비워둔 것이 그대로 쓰인다.

### 브라우저 의존성

| 패키지 | 역할 | 브라우저에서 |
|---|---|---|
| pdfminer.six | PDF 텍스트·좌표 추출 | 순수 파이썬 · Pyodide 에서 import 성공 확인 |
| charset-normalizer | 인코딩 판별 | Pyodide 공식 배포에 포함 |
| cryptography 47.0.0 | 암호 걸린 PDF | Pyodide 공식 배포에 포함 |
| Pillow 12.2.0 | 이미지 처리 | Pyodide 공식 배포에 포함 |
| **pypdfium2** | 페이지를 그림으로 렌더 | **없음** (네이티브 바이너리) |

`pypdfium2` 만 빠지는데, 실제로 필요한 자리가 한 곳뿐이다.

- `page.py:77` 의 `from .display import PageImage` 는 `if TYPE_CHECKING:` 블록 안 — 실행되지 않는다
- `page.py:598` 의 같은 import 는 `to_image()` 메서드 **내부** — 페이지를 그림으로 뽑을 때만 실행된다

즉 **표 추출 경로는 `pypdfium2` 를 거치지 않는다.**

검수 화면 왼쪽의 PDF 페이지 그림은 **PDF.js** 로 그리면 된다. 브라우저 기본 기술이고
파이썬을 거칠 필요가 없다. 오히려 이쪽이 빠르다.

### 이 검증의 한계

이 작업 환경이 Pyodide 패키지 CDN 을 차단하고 있어, **브라우저 안에서 PDF 를 끝까지
파싱하는 것까지는 실행해 보지 못했다.** 대신 두 갈래로 나눠 확인했다.

- 의존성이 브라우저에 존재하는가 → Pyodide 공식 패키지 목록(`pyodide-lock.json`, 356개)으로 확인
- 추출이 동작하는가 → 일반 파이썬에서 실제 PDF 로 확인

1단계 작업 중 네트워크가 열린 환경에서 한 번 더 확인할 것.

## 라이선스 메모

Pyodide 배포에 PyMuPDF 1.27.2.2 가 들어 있어 표 추출에 쓸 수도 있지만,
**AGPL 이라 사내 배포에 부적합**하다. pdfplumber(MIT) + pdfminer.six(MIT) 조합을 유지한다.

## 재현

```bash
cd scratchpad && npm i pyodide
uv build --wheel --out-dir wheels
node spike2.mjs     # 엔진 성능
```
